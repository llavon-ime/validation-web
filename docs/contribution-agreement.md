# 拉風輸入法驗證集貢獻同意書

目前版本：`2.0`

本同意書適用於投稿者透過本服務向拉風輸入法公開驗證集所為之投稿。投稿者完成必要勾選並按下「同意並繼續」後，即依下列條款作成授權、同意及聲明。

## 第一條　定義及適用範圍

一、「投稿內容」指投稿者透過本服務提交之前文、正確答案、逐字注音、整體判讀難度，以及就前述內容所作之修訂、標註或其他附隨資料；所稱整體判讀難度，包括語境歧義、詞彙罕見性、專業性及所需背景知識等因素。

二、「資料集」指由投稿內容彙整而成、公開於 GitHub repository 之拉風輸入法驗證集（validation dataset）。

三、「CC BY 4.0」指 Creative Commons「姓名標示 4.0 國際」公眾授權條款（SPDX：`CC-BY-4.0`），其法律效果以 [CC BY 4.0 正式法律條款](https://creativecommons.org/licenses/by/4.0/legalcode.zh-hant)為準。

四、「指定標示名稱」指「拉風輸入法組織（llavon-ime）」。該名稱僅為 GitHub Organization、專案社群名稱及各投稿者共同選定之別名與姓名標示名稱；其並非已登記之法人或其他法律實體，亦非投稿內容之著作人、著作權人、著作財產權受讓人或集中授權人。

五、本同意書適用於投稿者同意本版本後，以同一 GitHub 帳號透過本服務提交之各筆投稿內容。

一、本服務使用 GitHub OAuth 驗證投稿帳號、確認電子同意並防止冒名投稿。GitHub 並非本同意書之當事人，亦不因此審查、認可或擔保投稿內容。
